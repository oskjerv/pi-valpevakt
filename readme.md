

### Puppy watch :dog: :camera:

A setup for taking photos every nth minute of a puppy. 

###

When installing from `requirements.txt`, you need to allow system packages inside `.venv`in order to make `libcamera` visible inside the `.venv`:

```python3 -m venv .venv --system-site-packages```

### Execution

```python3 src/main.py```
